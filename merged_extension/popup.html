⚠️ Action Required — Enable Incognito Protection

To block sites in private/incognito windows, you must enable this extension for incognito mode. Without this step, children can bypass all blocks using private browsing.

  1. Click the ⋮ icon in your toolbar
  2. Click Extension
  3. Click "Manage Extension"
  4. Find Child Safety Module → Details
  5. Scroll to "Allow in Incognito"
  6. Toggle it ON
  7. Return here and continue setup
